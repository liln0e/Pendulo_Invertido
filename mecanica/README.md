# Diseño mecánico del péndulo invertido

Esta carpeta contiene los archivos relacionados con el diseño mecánico del **péndulo invertido autocontrolado**, incluyendo el chasis y los modelos preparados para fabricación.

## Contenido

- `pendulo_invertido.3mf` → Modelo 3D editable del chasis.
- `pendulo_invertido.gcode` → Archivo preparado para impresión 3D.

## Descripción

El chasis fue diseñado en **Fusion 360** y fabricado mediante **impresión 3D**, buscando:

- Centro de gravedad bajo.
- Distribución equilibrada del peso.
- Integración compacta de la electrónica.
- Facilidad de ensamblaje.

La documentación técnica completa se encuentra en [`../documentacion.md`](../documentacion.md).
